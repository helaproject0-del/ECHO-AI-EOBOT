# Hack Club submission checklist

- [ ] The physical robot is assembled and safe to power.
- [ ] Firmware builds for the exact ESP32-S3 board.
- [ ] README and wiring table match the real hardware.
- [ ] All source files and required dependencies are in this repository.
- [ ] Setup and build instructions work on a clean computer.
- [ ] API keys and Wi-Fi credentials are not committed.
- [ ] Gemini requests have been tested and errors are handled.
- [ ] Microphone capture and speaker playback have been tested.
- [ ] Both servos move reliably without brownouts.
- [ ] Demo video shows the actual working robot.
- [ ] Photos show the robot and internal wiring.
- [ ] Known limitations are stated honestly.
- [ ] Submission guidelines have been read.
